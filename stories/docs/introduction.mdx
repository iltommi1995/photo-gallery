# Photo Gallery

A self-hosted photography portfolio: a public site with a horizontally-scrolling
album viewer, and a private admin panel for uploading photos and composing each
album's layout.

## Stack

- **Next.js 16** (App Router, TypeScript strict, Turbopack)
- **Tailwind CSS v4** — CSS-first config, no `tailwind.config.ts`; design tokens
  live in `src/app/globals.css` (see the [Design System](/docs/design-system)
  page)
- **PostgreSQL + Prisma** (`prisma/schema.prisma`)
- **Auth.js v5** (Credentials provider, single admin account)
- **sharp** (image variant generation) + **exifr** (EXIF extraction)
- **@dnd-kit** (the admin album editor's drag-and-drop)
- **Vitest + Testing Library** (unit/component tests), **Playwright** (E2E),
  **Storybook 10** (this documentation)

## Two halves

**Public site** (`src/app/(public)/`) — Home, `/places` (album index),
`/places/[slug]` (the horizontal-scroll album viewer), `/about`. Everything
here reads from the database read-only and is statically generated with ISR;
see [Data Model](/docs/data-model) and [Horizontal Scroll](/docs/horizontal-scroll).

**Admin panel** (`src/app/admin/`, gated by `src/proxy.ts`) — album/chapter/photo
management. See [Admin Editor](/docs/admin-editor).

version. Where an implementation choice deviates from an original planning
document (e.g. Prisma major version, Storybook framework, image-format
strategy), the reasoning is called out inline rather than silently glossed
over — check `CHANGELOG.md` for the specifics and when each choice was made.
